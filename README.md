# Projeto Euclides Paradise

Este repositório contém o código do **Projeto de Extensão 1**, desenvolvido para a gameficação da **Geometria Plana**, de acordo com o **Objetivo de Desenvolvimento Sustentável (ODS) 4**.

O projeto foi construído a partir ideia de um jogo no estilo do **Candy Crush**, usando **polígonos euclidianos planos**.

---

## Estrutura do repositório

- `/src/components/piece.js` — Gera SVGs das peças;
- `/src/core/constants.js` — Armazena constantes das peças e das dificuldades;
- `/src/core/main.js` — Sistema principal do jogo;
- `/src/core/ranking.js` — Sistema de ranking;
- `/src/core/state.js` — Armazena dados da partida;
- `/src/systems/board.js` — Lógica principal do tabuleiro;
- `/src/systems/bomb.js` — Lógica da bomba;
- `/src/systems/combo.js` — Lógica de atualização do combo;
- `/src/systems/emergency.js` — Lógica do sistema de emergência;
- `/src/systems/gameover.js` — Lógica do fim de jogo;
- `/src/systems/hp.js` — Lógica da barra de vida;
- `/src/systems/input.js` — Lógica de entrada e movimentação das peças;
- `/src/systems/match.js` — Lógica de processamento de combinações e pontuação;
- `/src/systems/hp.js` — Lógica da barra de vida;
- `/src/systems/queue.js` — Lógica da fila de próximas peças;
- `/styles/style.css` — Estilo CSS da página HTML do jogo;
- `index.html` — Página principal do jogo; 
- `README.md` — documentação geral do projeto.
